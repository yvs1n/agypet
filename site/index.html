Per-chat awareness and voice sync

Matches the exact conversation you are viewing. Shows Typing when either you or the agent is writing, Listening during dictation, and flips live between Listening and Speaking in Voice Mode.

Multitasking and live servers

Juggles orbiting tasks when minimized with multiple active sessions, follows a single session directly, and displays a calm server rack when a finished chat keeps a live server running.

Adaptive perch with subtle press physics

Compiles in two seconds via Windows’ built-in .NET compiler. Tracks the composer card across Small, Medium, and Large sizes, attaches natively to Windows Terminal / PowerShell running agy CLI, docks on your taskbar, and wakes right up with a subtle startle when nudged.
